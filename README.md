# ИПР·AI · веб-интерфейс

Статичный фронт для GitHub Pages: HTML, CSS и ES-модули без сборки и без внешних библиотек. Стили перенесены из прототипа v10.

## Режимы

| Режим | Когда | Что работает |
| --- | --- | --- |
| Демо | GitHub Pages без шлюза (`apiBase: null` или `'demo'`) | Кейс Марины, сборка-имитация, ответ про время (снимки посчитаны заранее), «короче», вид руководителя, Word и PDF. Остальные правки показывают подсказку |
| Локальный шлюз | `npm run dev` в `ipr-core`, открыть http://localhost:8787 | Всё: вход по ссылке, сборка, вопросы, правки шагов, «не про меня», тьютор по ключевым словам, история версий, отправка руководителю |
| Облако | `apiBase` = адрес API Gateway в `config.js` | Как локально, но с YDB, Langflow и почтой |

Движка правил во фронте нет: выбор направлений и вопросы к встрече считает шлюз. В демо лежат снимки, посчитанные движком заранее (`demo/plan_demo.json`, пересобирается командой `node tools/build_demo.mjs ../ipr-web/demo/plan_demo.json` из `ipr-core`).

## Файлы

| Файл | Что делает |
| --- | --- |
| `index.html` | Каркас экранов из прототипа |
| `config.js` | Адрес шлюза |
| `src/app.js` | Экраны и действия: вход, материалы, сборка, уточнение, тьютор, готовый план, вид руководителя |
| `src/render.js` | Документ плана из PlanState и выгрузка для Word |
| `src/api.js` | Клиент шлюза и демо-режим |
| `css/app.css` | Стили прототипа плюс несколько дополнений в конце |
| `demo/` | Синтетические материалы кейса и снимки для демо |

## Выкладка на GitHub Pages

1. Репозиторий `ipr-web`, содержимое этой папки в корень.
2. Settings, Pages: Deploy from a branch, `main`, папка `/`.
3. Когда шлюз будет в облаке: в `config.js` указать его адрес, а в шлюзе в `WEB_ORIGIN` — домен Pages.

## Как скачивается план

- **Word**: документ собирается в браузере как HTML с расширением .doc. Word открывает его как обычный документ. Настоящий .docx — следующий шаг.
- **PDF**: печать браузера, служебные панели при печати скрыты.

## Чего пока нет

- Режима руководителя «дать вводные сотруднику» из прототипа: шлюз это умеет на уровне API (`mode: manager`), экрана ещё нет.
- Правки задач квартала после сборки: сейчас задачи меняются пересборкой с первого экрана.
- Загрузки PDF и Word: шлюз пока читает только текстовые файлы.
